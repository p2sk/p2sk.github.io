### 1. Aufwärmen – 5 min

### 2. Darttennis – 6–8 min

**Typ:** TA · G | **DC:** P | **Spieler:** Gruppe

Im gegnerischen Feld mit Kreide/Tape 3 gestaffelte Zonen aufmalen, **von innen nach außen wertend**: Mittelzone (großzügig, sicherer Bereich) = 1 Pkt · mittlerer Ring = 3 Pkt · äußerer Streifen direkt an den Linien (kurz vor Aus) = 5 Pkt. Kinder stellen sich in Reihe an der T-Linie auf und schlagen nacheinander über das Netz in die Zonen. Jedes Kind hat 10 Versuche – wer sammelt die meisten Punkte?

**Material:** Rote oder Orangebälle · Kreide/Tape (3 gestaffelte Zonen im gegnerischen Feld, außen wertvoller) · Schläger (Kurzgriff oder regulär)

**Dosierung:** 6–8 min · 10 Versuche pro Kind

**Platzbild:** Kinder in Reihe an der T-Linie · Zielzonen im gegnerischen Feld: Mitte groß/sicher (1 Pkt.) → außen schmal/riskant (5 Pkt.) · Schlag über das Netz

```
+------------------------+
|  	_________________	 |
|   |                |   |
|   |   __________   |   |
|   |   |         |  |   |
|   |   |         |  |   |
|---+---+---------+--+---+
|           |            |
|           |            |
|           |            |
|           |            |
|           |            |
---------------------------
```

**Steigerung:** nur Mittelzone + mittlerer Ring (einfach) → alle 3 Zonen inkl. Außenstreifen (DC: P) · Ball außerhalb der Zonen (Aus) = 0 Pkt., zählt als Versuch

**Varianten:** Wer schafft mit 10 Versuchen die meisten Punkte? · Wer schafft als Erster genau 20 Punkte?

_Anpassung: aus AS-A08 herausgelöst (Teil a); Ziel von Wand/Zaun auf den Platz verlegt (Schlag von der T-Linie über das Netz); Zonenwertung umgekehrt zum klassischen Dartboard – außen gibt mehr Punkte als die sichere Mitte, analog zur Zonenwertung in `GS-G26/GS-G27`._

**Passt-zu:** AS-A07 · AS-A09 · Mensch-ärgere-dich-nicht-Tennis (Folgespiel)

### 3. Mensch-ärgere-dich-nicht-Tennis – 6–8 min

**Typ:** TA · G + K | **DC:** P + K | **Spieler:** Gruppe

2 Mannschaften; Aufschlagfeld der Gegenseite in 4 gleiche Viertel einteilen (Kreide/Tape). Beide Teams stellen sich in fester Schlange an der Grundlinie auf. Es schlägt immer nur ein Kind gleichzeitig auf, strikt alternierend Team A/Team B. Trifft ein Kind ein leeres Viertel, läuft es direkt rüber und stellt ein Hütchen seiner Farbe hinein – die Schlange wartet, bis das Hütchen steht. Danach zurück ans Ende der eigenen Schlange, dann ist die andere Mannschaft dran. Sieger: Mannschaft, die zuerst in allen vier Vierteln ein eigenes Hütchen hat.

**Material:** Rote oder Orangebälle · Kreide/Tape (4 Viertel im Aufschlagfeld) · Hütchen in 2 Farben (je 4 pro Mannschaft) · Schläger (Kurzgriff oder regulär)

**Dosierung:** 6–8 min

**Platzbild:** 2 Teams in fester Schlange an der Grundlinie · Aufschlagfeld der Gegenseite mit 4 Vierteln markiert · TR seitlich, ruft Reihenfolge „A" / „B"

**Steigerung:** Hütchen-Entfernen-Variante – trifft ein Kind ein bereits belegtes gegnerisches Viertel, wird das gegnerische Hütchen entfernt (DC: K)

**Varianten:** mit 2 Bällen gleichzeitig (Tempo, nur wenn Reihenfolge sicher sitzt)

_Anpassung: aus AS-A08 herausgelöst (Teil b); Ablauf um feste Wechsel-Reihenfolge ergänzt (nur 1 Kind aktiv, Schlange wartet – Chaosvermeidung)._

**Passt-zu:** Darttennis (Vorspiel) · AS-A09

**Organisation:** Beide Untergruppen (15-2-RO/15-3-RO) zusammen oder getrennt je nach Feldverfügbarkeit; bei 9 Kindern ggf. 2 parallele Durchläufe.

**Lernziel der Einheit (Wozu):** Nach kurzem Einschlagen im 10er-Spiel unter wechselnden Gegnern bestehen; Aufschlag als Steigerung einbauen.

### 1. Einschlagen kurz → lang – 5–6 min

**TS-03 | Kooperation mit Aufwärmzonen** *(5–6 min)* · `🔴–🟡 · Spieler: 2er · TS · TA · DC: P`
Spieler starten nahe am Netz (Servicelinie). Rally kooperativ – nach je 5 Treffern einen Schritt zurück, bis an die Grundlinie. „Ziehharmonika." Gutes Aufwärmen für Koordination + Technik gleichzeitig.
Dosierung: 5–6 min

### 2. 10er-Spiel 2vs2 mit Partner-Rotation – ca. 20 min

**Typ:** TA · S | **DC:** Si + K | **Spieler:** 4 (2 Teams)

4 Spieler starten in zwei Zweier-Teams (z. B. Louis Köneke + Louis Ayas vs. Viktor + Finn). Nach dem allerersten Punkt rotiert sofort ein Spieler aus Team A zur Gegenseite – ab da werden nacheinander alle drei möglichen Paarungen durchlaufen (Louis K./Louis A. vs. Viktor/Finn → Louis K./Viktor vs. Louis A./Finn → Louis K./Finn vs. Louis A./Viktor), sodass jeder mit und gegen jeden spielt statt immer denselben Gegner zu haben. Gespielt wird bis 10 Punkte insgesamt.

**Material:** reguläre Bälle · Feld nach Gruppenstand (Midcourt/Großfeld)

**Dosierung:** 3 Runden (je Paarung ein Abschnitt) à ca. 5–6 min

**Platzbild:** 2 vs. 2, Rotation nach festem Schema (siehe Ablauf)

**Steigerung:** Start mit Zuspiel/Einschlagen ins Spiel → sobald sicher: jeder Punkt beginnt mit echtem Aufschlag

_Anpassung: eigene Spielform nach Trainer-Vorgabe (Partner-Rotation für wechselnde Gegner), kein Katalog-Eintrag._

### 3. DP-A08 – Netzüberfall: dynamischer Netzangriff während der Rallye – ca. 20 min

**Typ:** TA · S | **DC:** Si + K | **Spieler:** 4 (2 Paare)

Alle 4 starten an der Grundlinie, je 2 pro Seite. Anspieler (A) spielt den Ball zum Angespielten (C) auf der Gegenseite an – A und C bleiben an der Grundlinie und spielen die Rallye normal zu Ende. Die jeweils anderen beiden (B, Partner von A, und D, Partner von C) sprinten sofort nach dem Anspiel Richtung Netz und versuchen, im Verlauf der Rallye einen Ball als Volley abzufangen. Fängt B oder D erfolgreich ab und gewinnt den Ballwechsel direkt, zählt der Punkt für das jeweilige Team; fangen sie nicht ab, wird die Rallye zwischen A und C normal zu Ende gespielt. Rollentausch nach jedem Punkt (rotierend durch alle 4 Positionen: Anspieler → Angespielter → Netzläufer → Netzläufer).

Trainer ist Spielleiter, achtet auf: Timing des Losrennens, Kommunikation zwischen den Netzläufern, faires Auszählen bei Abfang-Volleys. **Keine Technikkorrektur.**

**Material:** keine Extras

**Dosierung:** Satz bis 11 Punkte · Rollentausch nach jedem Punkt

**Platzbild:** A + C an der Grundlinie gegenüber (rallyen) · B + D sprinten nach Anspiel Richtung Netz (je eigene Seite)

**Steigerung:** Netzläufer dürfen erst ab dem 2. Ballwechsel-Kontakt eingreifen (Rallye darf sich erst aufbauen) → Netzläufer dürfen sofort nach dem Anspiel eingreifen (DC: Z) → Nur Volley-Winner zählt als Bonus-Punkt für die Netzläufer, sonst geht die Rallye normal weiter (DC: K)

**Varianten:** Nur einer der beiden Partner rennt (der andere bleibt Absicherung an der Grundlinie)

**Passt-zu:** eigenständige Spielform, keine Erwerbsreihe vorgeschaltet · neu im Katalog: `Doppel.md` DP-A08 / DP-G3
